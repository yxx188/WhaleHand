# 常见问题

## 获取与安装

**Q：从哪里下载？**
A：安装包由作者在社区渠道（QQ 群文件）分发，本仓库只做源码存档，不提供公开下载入口。每次发版会给出 SHA256 和官方签名指纹，只认渠道公告里的校验值。

**Q：安装提示「应用未安装 / 签名不一致」？**
A：说明手机上已有的版本是另一种签名（官方包 vs 你自己编译的包）。两个办法：备份聊天/记忆后卸载旧包再装；或者干脆别混装，认准一个来源。

**Q：支持哪些手机？**
A：最低 Android 14（`minSdk 34`）。作者在 vivo X200 / OriginOS 上长期验证，其他机型没有系统适配，遇到问题欢迎反馈。

**Q：必须开哪些权限？**
A：无障碍服务（必须，否则点不了屏幕）、悬浮窗（推荐，能看状态、随时停）、通知（前台服务保活）。Termux 工具通道是可选项，默认关闭。

## 模型与费用

**Q：必须用 DeepSeek 吗？**
A：不是。任何 OpenAI 兼容的 `/chat/completions` 接口都能填进「模型档案」，地址和模型名都可以改。

**Q：没有 API Key 能干什么？**
A：聊天和任务都要调模型，没有 Key 用不了核心功能。设置里可以看记忆、日志、配置，但聊天发不出去。

**Q：一次任务要花多少钱？**
A：按你选的 provider 计费。每一步决策都是一次请求，20 步的任务就是 20+ 次请求；长任务又慢又贵。想省钱：换便宜模型、目标写具体、少开视觉外挂、别跑长任务。

**Q：Key 存在哪？安全吗？**
A：存在 App 私有目录的 SharedPreferences 里，**明文本地存储**。普通 App 读不到，但 Root、备份提取、脱机破解可以。泄露了立刻去平台换 Key；不要把含 Key 的截图或配置文件发到群里。

**Q：视觉外挂必须开吗？**
A：不必须。默认关闭；开了需要单独配置一个支持图片输入的模型。

## 使用

**Q：它会不会乱点？**
A：每一步都由模型决策，同时有几道安全阀：应用黑名单、支付/验证码/指纹页面暂停、完成判定要引屏幕原文、步数上限。但**不能保证 100% 拦得住**，建议先拿不重要的 App 试。

**Q：卡住了怎么办？**
A：直接点悬浮条/通知里的停止。去任务台看日志，把卡住的应用加进黑名单；要反馈的话，把日志最后 10 行脱敏后发出来。

**Q：为什么它认不出某个界面？**
A：H5、游戏、自绘界面的控件树经常是空的。可以开视觉外挂，或者把任务拆得更小更具体。

**Q：无限制模式是什么？**
A：需要 Root + 口令解锁的调试模式，放宽步数上限。普通用户不建议开，主力机更不要开。

**Q：记忆里存了什么？**
A：操作路径、界面入口这类稳定知识，不会主动记密码。可以在「设置 → 数据与工具」里查看、编辑、清空。

## 更新与反馈

**Q：怎么更新？**
A：跟随渠道公告。同签名直接覆盖安装；跨签名先备份数据再卸载重装。

**Q：怎么反馈 bug？**
A：带上：机型 + Android 版本 + 系统、WhaleHand 版本、任务目标、失败前最后 10 行日志、是否开了视觉外挂。记得删掉 Key 和隐私内容。源码层面的问题再开 GitHub Issue。

**Q：能拿去做二次整合 / 收费发行吗？**
A：不能。项目是 GPL-3.0：改了必须同样开源；官方名称、图标、签名不得冒用；修改版必须改名换图标。

**Q：能打赏吗？**
A：自愿，渠道见社区公告。打赏不影响授权，也不代表任何功能承诺。
